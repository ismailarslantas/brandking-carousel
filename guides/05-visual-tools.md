# Visual tool and composition library

Use tools because they clarify a message. This is a creative library; not every concept is implemented as an executable layout. See `docs/PLAN.md` for actual renderer support.

## Visual tools

- Typography: oversized type, one emphasis strip, repeated words as a quiet texture, large diagonal capitals, short script plus capitals, a restrained numeric highlight.
- Navigation and information: arrow badge, page counter, small category pills, icon-led feature strip, numbered list, check rows. Use consistent vector icon language instead of emojis.
- Cards: bento grid, floating feature cards, layered photos, asymmetric corner panels, package/tariff comparison, avatar row when real authorized portraits exist.
- Metaphors: calendar for a genuine period, key for access, door for invitation, timer for a supported speed claim, signpost for coverage, magnifier for detail. Choose one strong prop.
- Framing: arch mask, approved brand-shape mask, nested frame, natural foliage, controlled out-of-bounds object, concentric circles or an understated Venn relationship.
- Scenes: split comparison, realistic product reflection, hands directing attention, appetizing flow for food, brand duotone, quiet organic shape, category-specific paper/wood/board texture.
- Concepts: objects arranged into a meaningful symbol, restrained personification, surreal scale or product/type interaction. Preserve legibility and actual product identity.

Avoid decorative effects without a message, cliché office handshakes, invented platform screenshots, fake social proof, dense UI imitations and product masks that cut off labels.
