# Topic to tool matching

Tool choice is never random. The topic says which tool works. Tools and compositions are defined in [05-visual-tools.md](05-visual-tools.md).

This table is independent of sector. Start with **what you are saying**.

## 3. Selection flow

For each post, in order:

1. **What is the message type?** Take composition and tool candidates from section 1.
2. **What is the sector?** Set branch, palette and footer from section 2.
3. **Has this composition been used in the series?** If so, take the next candidate.
4. **Did the previous post use this rotation?** If so, change it.
5. **Is there a photo?** With one, use R2 or R5. Without one, use R1, R3 or R7 with prop or type-led tools.

## 4. No photo available

These tools work without photography: giant type lock, repeat wall, diagonal type, bento grid, number badges, blob card, symbol field, organic blob field, category texture, label pill row, tone-on-tone pattern, package cards, hybrid poster type, frame within a frame.

At least four of nine posts can be built this way. It also helps a grid by creating breathing room. Do not fill empty space with unrelated stock art.
