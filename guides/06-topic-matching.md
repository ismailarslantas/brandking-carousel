# Match the message to the visual

Selection order: message type → composition candidates → brand identity → available assets → sequence repetition check. Sector defaults are starting points only.

| Message | Candidates | Useful device |
| --- | --- | --- |
| Brand manifesto | N, D | Large clear type |
| Product introduction | A, D, B | Real product hero |
| Concrete benefit | B, C | Simple information panel |
| Feature list | K, L, I | Cards or icon strip |
| Price/campaign | M, G | Verified price panel and real terms |
| Education | F | One explanation or checklist |
| Objection | H, F | Comparison or clear answer |
| Time/speed | N, E | Timer only for a supported claim |
| Coverage | G, E | Real map/signpost |
| Quality/detail | D, E | Magnification or close texture |
| Invitation | E, G | Door or access metaphor |
| Audience groups | A, L | Labeled segments |
| Question | E | Conceptual prompt with a real payoff |
| Social evidence | M, H | Real sourced quote or number |
| Season | G | Accurate date/calendar |
| Emotional connection | D, B | Genuine human context |
| Digital product | L, K | Real supplied screen |
| Transformation | A, H | Honest before/process/after |
| Product range | P | Explicit variant exception |
| Packages | Q | Comparable terms |
| Team | O, A | Authorized portraits |
| Food/sensory | S, N | Macro texture or product flow |
| Portfolio | O, J | Real work and clear labels |

Brand tone defaults: agriculture often grounded and practical; family/health warm and evidence-led; education/software clear and useful; B2B calm and precise; luxury quiet/editorial; food sensory and concise; property factual and reassuring. None of these defaults authorizes a new palette, invented promise or unsupported sector claim.

If there is no photo, use typography, comparison panels, geometric information graphics or meaningful objects. Do not fill empty space with unrelated stock art. Check that adjacent slides do not repeat the same composition and palette role.
