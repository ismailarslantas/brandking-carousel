# GitHub banner art direction

Format: landscape README banner. Creative direction: Visual Post & Carousel Director plugin. Rendering: built-in image-generation tool; not part of the free repository runtime.

## Copy

Eyebrow: BRANDKING CAROUSEL

Headline: Your brand. Every swipe.

Supporting line: Free. Local-first. Claude-ready.

## Placement

Left: large geometric sans copy with generous margins. Right: three overlapping portrait carousel cards with varied compositions and one consistent identity. Dark forest field, ivory text, one lime accent. Matte finish and restrained shadows. No generic robot, dashboard or decorative noise.

## Production prompt

Create a premium landscape GitHub README banner for an open-source project. Wide 2:1 canvas. Text-first, one conceptual idea, disciplined geometric sans typography, consistent identity with varied layouts. Exact text: eyebrow "BRANDKING CAROUSEL"; headline on the left in two large bold lines "Your brand." and "Every swipe."; small subline "Free. Local-first. Claude-ready." On the right show three elegant overlapping portrait 4:5 carousel cards: acid lime with dark huge typography "MAKE IT CLEAR", warm ivory with a black abstract editorial shape and "BUILD TRUST", charcoal with a fine-line abstract grid and "STAY YOU". Matte paper/card finish, subtle soft shadows, Swiss editorial direction. Background #111A17, text #F4F1E8, accent #D6F75A. Generous margins, strong hierarchy, accurate English typography. No photographic people, glitter, gradients, fake dashboard, brand-platform logos, watermark or additional text.
